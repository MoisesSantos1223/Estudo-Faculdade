# Portfólio Pessoal

No início do trabalho, utilizei inteligência artificial para estudar os requisitos da atividade e acelerar o desenvolvimento do projeto.

## Apresentação

Este site é um portfólio pessoal desenvolvido para apresentar minha formação, meus conhecimentos e alguns dos projetos que fiz durante meus estudos. O visual usa tons escuros e detalhes em rosa que eu achei em um video no tiktok e pegando umas referencias no site: https://themes.3rdwavemedia.com/instance/bs5/.

## Sobre o site

O portfólio foi criado com HTML e CSS. A página inicial apresenta minhas habilidades, trajetória, projetos e um formulário demonstrativo de contato. Também há páginas separadas para meu currículo, meus projetos e meus estudos de HTML e CSS.

## Sobre IA

Eu utilizei a inteligência artificial para me ajudar com ideias e conseguir sair do zero. Usei a IA como uma ferramenta de aprendizagem: sempre que pedia ajuda ao chat para escrever o código, também pedia uma explicação sobre ele. Além disso, utilizei a ferramenta para acelerar o trabalho, então uma boa parte do código CSS foi feita pela IA. Já no HTML, eu a utilizei como um professor
