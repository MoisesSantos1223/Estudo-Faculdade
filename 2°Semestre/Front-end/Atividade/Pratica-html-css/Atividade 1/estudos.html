MEUS ESTUDOS

Como estou criando meu portfólio

Estou aprendendo a combinar HTML e CSS para organizar o conteúdo e criar o visual das páginas.

ESTRUTURA

HTML organiza o conteúdo

Uso elementos como <header>, <nav>, <main> e <section> para separar as partes da página e dar significado ao conteúdo.

APARÊNCIA

CSS define o visual

Com o CSS escolho cores, tamanhos, espaços e alinhamentos. Neste site, os cartões e os detalhes rosa ajudam a destacar cada seção.

ADAPTAÇÃO

O site em telas menores

As regras de tela do CSS reorganizam menus, colunas e cartões para que o conteúdo também fique legível em celulares.

Etapas que sigo

  1. Organizo cada página com HTML semântico.
  2. Conecto o arquivo style.css para aplicar os estilos.
  3. Confiro os links e a aparência em diferentes tamanhos de tela.

Para continuar estudando, consulto a documentação da MDN sobre HTML e o guia da MDN sobre CSS.
