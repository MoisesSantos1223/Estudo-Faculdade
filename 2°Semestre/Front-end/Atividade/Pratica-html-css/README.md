# Portfólio pessoal

**Autor:** Moisés Henrique Dos Santos Sodré

Site de apresentação pessoal feito para um trabalho escolar usando HTML e CSS. O visual escuro com detalhes rosa foi inspirado no vídeo de referência guardado em `ArquivoDeIa`.

## Arquivos e pastas

- `index.html`: página inicial com seções de apresentação, habilidades, projetos, trajetória e contato.
- `curriculo.html`: formação e conhecimentos.
- `blog.html`: artigo introdutório sobre HTML e CSS.
- `projetos.html`: lista de projetos.
- `style.css`: estilos compartilhados entre as páginas.
- `imagens/placeholder.svg`: imagem temporária para substituir quando escolher uma foto.

O projeto usa apenas HTML e CSS, sem JavaScript, e tem menos de 300 linhas de HTML e CSS somadas. Troque os endereços de redes sociais e o e-mail de exemplo quando quiser adicionar os seus.
