# Aqui chat os requesito 
Crie uma página web de apresentação pessoal (Currículo/Portfólio Pessoal Simples) utilizando apenas HTML e CSS.  O objetivo é praticar os fundamentos do desenvolvimento web front-end, incluindo estruturação semântica, estilização, posicionamento e design.


Requisito da página:


Quantidade de Páginas - seu site precisar ter no mínimo 4 páginas com conteúdos diferentes, por exemplo (e não limitado à ):

    index.html - página inicial com mensagem de boas vindas, menu de navegação breve resumo sobre o conteúdo do site.
    curriculo.html * - versão web do seu curriculum vitae (formação academica, experiencia profissional, competencias, etc.)
    blog.html - conteúdo de ao menos uma página sobre um tema técnico de front-end (aproveite para incluir imagens e vídeos).
    fotos.html * - galeria de fotos contento imagens da internet de sua preferência (você pode ilustrar alguns hobbies - aproveite para praticar o posicionamento)
    contato.html /cadastro.html - formulário que o usuário da sua página irá preencher com informações pessoais e uma mensagem para que ele entre em contato com você (apenas formulário, não precisa funcionar no lado do servidor).


* não informe dados pessoais reais que não queira compartilhar (apenas nome completo já é suficiente), se necessário preencha o currículo com textos, valores e imagens placeholder.


HTML

    Estrutura semântica adequada (header, nav, main, section, footer);
    Título da página (<title> e <h1>);
    Uso de <div> para separar contextos;
    Menu de navegação com pelo menos 3 links;
    Imagens com atributos alt descritivos;
    Listas ordenadas ou não ordenadas;
    Formulário de contato simples (nome, email, mensagem);
    Links externos e âncoras internas.


CSS

    Estilização dos diferentes elementos da página (textos, menus, formulários, botões);
    Uso de classes e IDs apropriados;
    Cores definidas em paleta harmoniosa;
    Consulte: https://coolors.co/palettes/trending


Boas práticas

    Código bem indentado e organizado;
    Comentários no código quando necessário.
