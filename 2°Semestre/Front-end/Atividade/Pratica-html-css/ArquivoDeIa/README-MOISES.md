# Resumo do meu portfólio

Meu site é um portfólio escolar feito com HTML e CSS. Ele tem quatro páginas: início, currículo, blog e projetos. O visual escuro com detalhes rosa foi inspirado no vídeo que coloquei na pasta `ArquivoDeIa`.

## O que já tem

- Minha apresentação e minha formação em Análise e Desenvolvimento de Sistemas.
- Seções de habilidades, projetos, trajetória e contato.
- Um formulário de exemplo que não envia as informações.
- Espaços provisórios para a foto e para os links das minhas redes sociais.
- Nenhum JavaScript; o total dos arquivos HTML e CSS fica abaixo de 300 linhas.

## Tags HTML usadas

- `<header>` e `<nav>`: mostram o cabeçalho e os links do menu.
- `<main>`: contém a parte principal da página.
- `<section>`: separa os assuntos em partes.
- `<article>`: agrupa um cartão ou conteúdo independente.
- `<h1>`, `<h2>` e `<h3>`: criam títulos em níveis diferentes.
- `<p>`: mostra parágrafos.
- `<ul>` e `<li>`: criam listas.
- `<a>`: cria links para páginas e seções.
- `<img>`: mostra uma imagem; `alt` descreve a imagem.
- `<svg>`: desenha os ícones das redes sociais no HTML.
- `<form>`, `<label>`, `<input>` e `<textarea>`: montam o formulário de contato.
- `<button>`: cria o botão do formulário.
