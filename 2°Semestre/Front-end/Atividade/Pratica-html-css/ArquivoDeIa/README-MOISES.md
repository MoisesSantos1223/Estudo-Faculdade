Meu site é um portfólio escolar feito com HTML e CSS. Ele tem quatro páginas: início, currículo, projetos e estudos de front-end. O visual escuro com detalhes rosa foi inspirado no vídeo que coloquei na pasta `ArquivoDeIa`.

- Um formulário de exemplo que não envia as informações.
- Minha foto de perfil e links funcionais para meu GitHub e LinkedIn.
- Nenhum JavaScript; os arquivos HTML e CSS ainda precisam ser reduzidos para ficar abaixo do limite combinado de 300 linhas.

## Tags HTML usadas

- `<header>` e `<nav>`: mostram o cabeçalho e os links do menu.
- `<main>`: contém a parte principal da página.
- `<section>`: separa os assuntos em partes.
- `<article>`: agrupa um cartão ou conteúdo independente.
- `<h1>`, `<h2>` e `<h3>`: criam títulos em níveis diferentes.
- `<p>`: mostra parágrafos.
- `<ul>` e `<li>`: criam listas.
- `<a>`: cria links para páginas e seções.
- `<img>`: mostra uma imagem; `alt` descreve a imagem.
- `<svg>`: desenha os ícones das redes sociais no HTML.
- `<form>`, `<label>`, `<input>` e `<textarea>`: montam o formulário de contato.
- `<button>`: cria o botão do formulário.
