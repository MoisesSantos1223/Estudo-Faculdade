CADERNO DE ESTUDOS

HTML e CSS

Duas tecnologias que estou aprendendo a usar juntas.

HTML organiza o conteúdo

HTML estrutura o que aparece em uma página. Títulos, parágrafos, listas e links são escritos usando tags.

CSS cuida da aparência

CSS define cores, fontes, espaços e a posição dos elementos. Separar o HTML do CSS ajuda a organizar o projeto.

Por onde começar

  1. Organize o conteúdo com HTML.
  2. Conecte o CSS com a tag <link>.
  3. Estilize a página e confira no navegador.

Para estudar mais: guia de HTML da MDN e guia de CSS da MDN.
